### **Intro**: pheme_data_filter.ipynb 和 weibo_data_filter.ipynb
这两个文件是数据过滤和特征提取笔记文件, 最后达到特征提取的效果。

### 方法一：构建 Post-Comment 异质图（Heterogeneous Graph）
🌟最推荐方法之一：能结合结构和内容，建图后可使用 GAT/RGCN/HGT 处理。

节点设计：
- 帖子节点（post）
- 评论节点（comment）
- 可选用户节点（user）

边设计：
- Post → Comment（表示这条评论属于这条帖子）
- Comment → Comment（表示评论之间的回复/引用）
- User → Comment（谁发了这条评论）

节点特征：
- 帖子节点特征 = 图文融合特征（如你已有的ViT+RoBERTa）
- 评论节点特征 = 评论文本的RoBERTa/bert/sbert 编码结果
- 用户节点特征（如果引入）= 用户历史发言的平均 embedding 或 profile embedding

模型结构：
- 图神经网络（GAT、RGCN、HGT、HetGNN 等）编码图结构
- 获得帖子节点的最终表示后接 MLP 分类是否为 FakeNews

### 方法三：评论进行情感分析 / stance detection 作为辅助特征
评论中往往能体现出“群众眼睛是否雪亮”。

针对每条评论做情绪/立场分类，例如：
- 情绪标签：正向 / 中性 / 负向
- 立场标签：质疑 / 支持 / 中立

然后统计整条帖子的评论“情绪分布”或“立场分布”：

```python
support_rate = # 支持评论的占比
doubt_rate = # 质疑评论的占比
```
把这些统计结果拼接到最终分类器的输入中（MLP的输入特征）

### 方法四：使用评论做对比学习 / 多任务学习
- 评论 vs 原始帖子的语义一致性，作为一个对比任务：
    - 评论文本和帖子是支持关系 → 正样本
    - 评论与帖文无关或反对 → 负样本
- 用 InfoNCE 或 Triplet Loss 强化语义表示学习
- 或者单独训练一个 评论生成 / 评论分类 的任务，再用其中间层表示辅助主任务
